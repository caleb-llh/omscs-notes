## Revocation of Resources
Notice so far that exokernel supports no abstractions. It only has mechanisms for securely giving resources to the library operating system. And the resource may be a space resource, memory, time resource or specific hardware resource like area of the graphic display and so on. Of course, exokernel keeps the scoreboard as to what resources have been allocated to different library operating systems and therefore at any point of time it can revoke the resources that have been given to a library operating system. Sort of similar to a student working in my lab. Similarly, exokernel has mechanisms for revoking resources from a library operating system. So, Exokernel has a revoke mechanism for exactly this purpose of revoking library operating system. And the revoke call, which is an up call into the library operating system, is going to give this library operating system a repossession vector saying these are the resources I'm taking away from you. For instance, it could say, you know, remember I gave you these page frames? Well, I'm going to reclaim those page frames.
